# Висюн (v1syun) — лендинг

Одностраничный сайт для бренда **Висюн**: брелки, антистрессы и футболки с буквами из фетра ручной работы (Катя, Москва). Заказы — Telegram [@pechenyushkina](https://t.me/pechenyushkina).

## Структура

```
index.html            — страница (10 блоков)
css/style.css         — стили
js/main.js            — скрипты (без библиотек)
img/                  — оптимизированные изображения WebP (две ширины: *-s.webp 480px и полная)
img/og.jpg            — превью для соцсетей 1200×630
video/                — сжатые ролики MP4 (H.264, без звука) + постеры WebP
favicon.svg, manifest.webmanifest
robots.txt, sitemap.xml, llms.txt — SEO и GEO (поиск в нейросетях)
```

## Блоки

1. Hero — логотип из «фетровых» букв (тап — буква подпрыгивает), брелок-колечко качается
2. Витрина с фильтром: антистрессы / брелки / одежда, кнопка «Хочу такого» копирует текст заказа и открывает Telegram
3. Тренажёр «Помни червяка» — интерактивный антистресс со счётчиком
4. Футболки: конструктор надписи (превью фетровыми буквами, цвет ткани и букв, футболка/лонгслив), характеристики, галерея
5. На заказ по эскизу + примерка цвета котика
6. Видео (подгружаются и играют только в зоне видимости)
7. Подарочный сертификат: номинал, кому/от кого, пожелание — живое превью, печать макета (A5), заказ в Telegram
8. Как заказать + бонус «от 3 изделий — бесплатная доставка или сюрприз»
9. Отзывы — слайдер (свайп, стрелки, точки, клавиатура, автопрокрутка с паузой)
10. FAQ + финальный призыв, подвал

Блока с картой нет: адрес мастерской не указан (только «Москва»). Если появится адрес — можно добавить карту Яндекса.

## Перед публикацией

- **Отзывы в блоке 9 — демонстрационные заглушки.** Замените их на реальные отзывы клиентов (из директа / Telegram) и уберите строку `.demo-note`.
- Замените домен `https://v1syun.ru/` на реальный в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`.
- Цена пушистых антистрессов и сюрприз-пакетиков не указана — сейчас «цена в тг».
- Номиналы сертификата (990 / 2000 / 3000 / 5000 / своя сумма) — предложение, при необходимости поменяйте в `index.html`.

## Технически

- Адаптив от 320px, бургер-меню на ширине до 980px, учтены safe-area для iPhone.
- Кроссбраузерно: Chrome, Safari (iOS/macOS), Firefox, Edge, Samsung Internet, Яндекс Браузер. Есть фолбэки для копирования в буфер и для браузеров без IntersectionObserver.
- `prefers-reduced-motion` — анимации отключаются.
- Шрифты: Nunito + Caveat (Google Fonts, кириллица).
- Разметка Schema.org: Store + OfferCatalog с ценами, WebSite, FAQPage. Open Graph, geo-метатеги (RU-MOW).
- Статический хостинг: файлы можно залить как есть (Netlify, GitHub Pages, Timeweb, Beget и т.п.).
